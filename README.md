# Tooku

面向中文用户的 Navidrome 第三方网页播放器。目标是让自己的音乐库更好找、更好听、更好看。

状态更新：2026-10-22。**可运行的开发工程，真实曲库已进行基础联调，尚未完成发布验收**。保留 Apple Music 的简洁视觉，主界面现采用 Spotify 式全局头部与三栏布局，明暗模式与主题色可选。本地 Git 已提交基线，本轮功能在 codex/library-workspace 分支；没有远程推送。

**Agent / 开发者接入：先读 [AGENTS.md](AGENTS.md)，再按任务查阅 [开发接入指南](docs/12-agent-development-guide.md)。** 两者说明当前模块入口、产品交互、数据边界与验证方式；早期设计文档包含已被替代的方案。

## 本地运行

需要 Node.js 24+（内置 SQLite 与 TypeScript 执行），本次使用 Node 24.15.0。**无需安装全局 pnpm**：已有依赖时可双击根目录 [start-tooku.cmd](start-tooku.cmd)，或通过 npm 启动。

```powershell
Set-Location G:\Code\Tooku
npm.cmd run dev
```

终端需保持运行，按 Ctrl+C 停止后地址将无法访问。电脑重启后双击启动脚本，脚本会启动服务并自动打开浏览器；需保持窗口打开。重复启动会打开已经运行的 Tooku。如果首次下载项目、尚无 node_modules，脚本会使用 `npx.cmd --yes pnpm@11.25.0 install --frozen-lockfile` 安装锁定依赖，不依赖系统 PATH 中的 pnpm。

默认打开 `http://127.0.0.1:18733/`；端口被占用或被 Windows 保留时，启动器会在 18733–18742 中尝试其他端口，实际地址显示在终端并写入本机 `.local/server-url.txt`。旧端口 5173 在本机 Windows 保留范围内，会报 EACCES，因此已更换。可通过进程环境变量 `TOOKU_PORT` 指定首选端口，无需更改系统网络设置。

登录页默认 `/nd` 经开发代理连接本机 `http://127.0.0.1:44533`。使用你自己的 Navidrome 用户名和密码；也可输入完整服务地址直连。账号和 token 只在内存，不写入环境文件。刷新页面需要重新登录，同一账号的本机队列可以暂停恢复。

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

现已实现：登录和扩展检测、专辑自动分批浏览、歌手横幅详情与播放、中文输入法安全的检索、收藏、普通歌单与保存核实、常驻播放器、队列与循环/随机、本地/网络双语歌词与偏移、浏览器全屏与桌面画中画歌词、Last.fm / AI 推荐及四平台外链、Media Session、账号数据同步/备份恢复、本机快照/收听历史、响应式与主题设置。**实现不代表所有 Navidrome 音频格式、权限和扩展都已实测。**

当前功能、最近检查及未测边界统一见 [开发记录](docs/09-development-status.md)。网络歌词与本地双语整理现已接入；PWA、拼音搜索、逐词动画和高级音频实验尚未实现。路线图保留为历史规划，不自动扩大开发范围；推荐“不感兴趣”反馈已按用户要求暂缓。

从头像进入「账户与设置」，按账户与音乐库、外观、播放与操作、网络歌词、音乐推荐、用户数据六类浏览。窄内容区使用顶部分类；切换分类保留未保存的推荐配置与检测结果，播放侧栏布局集中在播放分类，备份恢复与本机快照集中在用户数据。

主页统一从「全部」开始，不再设置默认浏览入口。外观支持自选主题色与输入六位色值；歌词检测用状态灯和文字显示结果。推荐设置中的 Apple Music / Spotify 默认折叠，保存按钮位于表单末尾；「新歌手目标占比」以本次收听样本为参照。用户数据可选择「保存到服务器」或「从服务器恢复」，确认后才覆盖对应数据。

左栏“最近在听”下方为“为你推荐”，主页“全部”提供简洁的文字入口板块，不展示歌曲明细。使用最近 30–50 首不同歌曲，手动生成 10 / 20 / 30 首（默认 30），推荐页与设置均可调整数量。Last.fm 平衡全部提交样本，候选不足时延伸探索；AI / 混合模式可提名经目录核实的新歌，略过或筛选后不足时按缺额最多追加两轮，达到目标即停止；上游持续失败时保留真实结果并说明缺额。同歌手、已知同名专辑最多一首，避开最近推荐过的 300 个 ID，并比较近期 90 首的歌名/歌手及已知录音室版本标记，减少跨平台重复；现场、翻唱、混音与未知版本保持区分。推荐页只保留一个主标题和一行批次信息，采用与歌单一致的文字列表，歌名、歌手分列，显示专辑、可信发行日期和时长，缺失为“—”，不放封面占位图。进入推荐页即分组核实整批网易云、QQ、Apple Music、Spotify 链接；点击歌曲打开平台菜单，未完成时显示核实提示；失败直接使用搜索入口，不增加重试操作，不播放、不下载图片。目录查询与 Spotify 临时令牌在服务内存中受限复用，减少生成后重复查链接；Last.fm 明确认证失败或限流时停止后续查询，AI 仍可独立继续。展开“收听参考”可查看将提交的样本；结果标明实际使用的算法/AI/混合模式。普通设置、最近结果及有限避重元数据按账号保存，密钥仅会话内存；推荐质量仍需实际收听判断。详见 [音乐推荐](docs/16-music-recommendations.md)。

推荐设置的检测结果直接显示在各服务按钮旁。Last.fm 使用 API key，无需 Shared secret；DeepSeek 建议填写 `https://api.deepseek.com/v1`，旧根地址统一使用同一接口。检测和生成共用非思考 JSON 模式、Node 默认与系统已信任 CA，保持严格 TLS 校验；成功会明确显示 JSON 输出正常，空内容、截断、认证、余额、网络等故障分别提示。修改系统证书信任后需正常重启 Tooku。

底部播放栏新增“桌面歌词”按钮，通过文档画中画打开置顶小窗，逐句显示原文与已有译文，跟随切歌、歌词来源、显示设置与同步偏移；没有时间轴的歌词可手动滚动。浮窗沿用应用主题，可拖动和缩放，关闭不影响音乐。需浏览器支持 Document Picture-in-Picture（如新版桌面 Chrome / Edge），远程部署需 HTTPS，本机 `127.0.0.1` 可用；不支持或打开失败会提示。初始请求 480 × 180，位置由浏览器决定，通常位于右下角，后续沿用浏览器记住的位置与大小，网页无法强制指定坐标。刷新、退出登录或关闭主页面会关闭浮窗，不自动重开。

展开播放器使用柔化封面背景，左侧封面与播放控制固定，超长歌曲名和歌手名在固定单行区域内往返滚动，悬停或聚焦暂停、减少动态效果时手动查看；封面、列间距与歌词字号随可用宽高缩放，适配 1K / 2K / 4K 和浏览器缩放；右侧大字歌词限制阅读区高度，当前句位于中部略上，右上角收起。收藏旁三点菜单提供查看专辑、歌手、当前来源歌单和添加到歌单；无歌单来源时禁用查看歌单。底栏收藏紧邻歌曲名与歌手名，随文字宽度移动。展开界面不放音量、底部歌词设置、队列切换和装饰小字。手动浏览歌词时显示“同步”，闲置 5 秒后自动跟随当前行并收起按钮。随机播放后，在相同专辑、歌单或来源列表内点歌会保留随机模式；切换其他来源默认顺序播放。来源、随机模式与关闭随机时的原始顺序随队列保存，旧快照仍可读取；旧队列没有来源信息时，从歌单重新点播即可记录。

新版主页展示曲库概览，支持全部、歌单、专辑、歌手筛选，歌手卡片可进入详情；底部不放曲库名与“浏览所有歌曲”小字。Logo/后退/前进/主页/搜索位于头部，账户设置只从头像菜单进入，菜单也可快速切换真实曲库。专辑页随滚动自动读取，保留排序与失败重试；歌手详情统一为柔化背景与方形前景图片，管理员可悬停/聚焦图片后更换并裁剪，保存到 Navidrome，其他客户端可读取；右键可恢复服务器默认图片。原有 Tooku 私人图片保留，不自动上传覆盖服务器图片。默认依次使用 Navidrome 歌手图、本库专辑封面、主题渐变。播放与专辑区域使用纯色背景，全部页面、左侧歌单与右侧播放栏提供贴边的 8 px 半透明浮动滚动条，悬停变亮、无上下箭头；弹窗与菜单使用统一透明轨道样式。右栏整合正在播放与队列，支持调整宽度、版块与顺序；左栏歌单树独立管理，文件夹默认展开，展开/折叠状态按账号保存到浏览器，通过 `/nd` 登录时也同步到 Tooku 数据库。歌曲表格支持列宽调整、空白区域双击播放和统一右键操作；歌单与文件夹在左栏拖动排序，使用横线落点与精简名称预览，主体管理页仅浏览；歌单内歌曲拖动后直接保存，不显示成功提示或撤销按钮，失败时可重新读取核实；封面点击直接选图裁剪，名称和简介从三点菜单编辑，编辑弹窗的封面与右侧表单上下对齐。长歌单时长仅显示约整小时。主体卡片和左栏文件夹不放三点图标，保留右键管理；新建歌单无位置小字，根目录统一为 `/`。无编辑权限时显示锁与只读提示，服务器管理的曲目显示“自动维护歌单”，悬停或聚焦提示修改原 m3u/m3u8 文件后重新扫描。

**Tooku 现有 Node.js + SQLite 用户数据后端。** 使用 `/nd` 登录后，自动保存头像、歌单封面、旧版私人歌手图片、目录、偏好、队列和历史。服务器为空时自动上传原浏览器数据；新浏览器本地没有个性数据时自动读取服务器，无需手动确认迁移。已有浏览器数据保留，只有两端都有不同个性数据或待核实的保存结果时，才从头像 → 账户与设置 → 用户数据预览选择版本。已连接设备在下次登录读取新版本，不实时接管另一设备的播放。完整服务地址直连仍可使用，Tooku 个性数据仅保存本地。名称、简介、歌曲和曲序等歌单数据继续保存在 Navidrome；新上传的歌手图片也直接由 Navidrome 保存，不占 Tooku 账号文档。图片编辑需原生 API 管理员会话，更新后请重新登录；原生认证失败不影响听歌。

默认数据库 `.local/data/tooku.sqlite`，可用进程环境变量 `TOOKU_DATA_DIR` 指定持久化目录；不要放在构建输出目录。生产运行先执行 `npm.cmd run build`，再执行 `npm.cmd start`，默认监听 `127.0.0.1:18733`；可用 `TOOKU_HOST` / `TOOKU_PORT` 调整。生产运行不依赖 node_modules；`npm.cmd run preview` 仅预览静态资源，不能替代 Node 服务。设置中可导出/恢复当前账号 JSON，管理员可用 `npm.cmd run backup -- .local/backups/tooku.sqlite` 创建新的完整数据库备份。恢复步骤、代理和数据边界见 [服务端持久化](docs/13-server-persistence.md)。

## 可选 Docker 部署

已准备 [Dockerfile](Dockerfile) 和 [Compose](compose.yaml)，使用 Node.js 同时提供静态页面、用户数据/歌词/推荐 API 和固定上游代理。Compose 将 `/data` 挂载到 `tooku-data` 卷，重建容器保留数据库。此电脑未安装 Docker，容器构建/运行仍待验证。`deploy/default.conf.template` 只用于可选的外层 Nginx 代理。

```powershell
docker compose up --build -d
```

配置通过 `http://127.0.0.1:8080/` 提供 Tooku，`NAVIDROME_UPSTREAM` 默认指向宿主机 44533；容器中的 localhost 是容器自身。若 Navidrome 位于其他容器/设备或子路径，先调整 Compose 中的上游地址（不要带尾斜杠）。Linux 上服务只绑定 127.0.0.1 时，host-gateway 并不保证能连接，应选择适合实际部署的网络方案。当前示例只绑定本机，远程使用需配置 HTTPS 与访问入口。

## 推荐路线

当前为 React + TypeScript + Vite 网页应用及 Node.js / SQLite 用户数据、独立歌词和推荐服务，以 Subsonic / OpenSubsonic 为音乐数据协议，使用常驻 HTMLAudioElement 播放。持久化、迁移与备份恢复已接入，歌单权限与保存核实已有实现；真实权限矩阵、长期播放、性能和部署仍待发布前验证。拼音搜索、逐词动画、PWA 和高级音频实验保留为未排期候选，不代表下一项已授权工作。

网络与双语歌词见 [独立歌词组件方案与实现](docs/15-lyrics-service-design.md)：组件随 Tooku 同端口启动，脱离 Navidrome 的网络查询与检测，支持网易云 / QQ 音乐；默认本地优先，明确缺失才联网。展开页顶部来源、歌词设置、全屏与收起图标同行，去掉胶囊外框并以竖线分组，QQ 使用企鹅图标；底栏最右按钮直接打开浏览器全屏播放器，退出全屏不改变音频。展开页右键复用当前歌曲更多选项；来源只有本地、网易云和 QQ，缺本地时自动采用网络相近版本；歌手匹配兼容多人合写、括号与平台别名，支持原文加括号译名的歌名，以及平台确认的中文/日文歌手名关联。网易云组合检索失败时受限回退为仅歌名检索，再按歌手/时长筛选；QQ 优先使用新版匿名明文接口显式请求译文，故障可回退旧接口，空译文时保留原文。“歌词设置”将显示、双语排版、同步偏移和版本搜索合并到一个面板；显示页使用“自动识别”双语格式，重置与刷新同行、保存独占一行，不放预览；内部滚动为输入框焦点边框留白，版本页先填歌曲标题和歌手，再选择平台并搜索，不放刷新按钮；纯音乐或最终无结果统一显示“该音乐没有歌词，请欣赏”。设置中的“网络歌词”可调整来源顺序、查看真实运行状态并检测。个人选择随账号备份，公开歌词放独立缓存，不写回标签。未知排版保留原文，可手动指定；不生成译文或时间戳。平台匿名接口可能变化，本次公开样本通过不代表全部歌曲可用。既有服务未加载新接口时，在停止播放后正常重启 Tooku 即可。

核心差异化：中文输入与检索体验、精致且可降级的歌词页、明确可控的播放队列、稳定的连续听歌流程。首页内容来自用户自己的音乐库。
