# 开发记录与验证边界

更新日期：2026-10-14；版本：0.1.0 开发版。产品名 Tooku，Apple Music 风格的简洁白色界面，本地 Git main 已初始化。没有创建远程仓库、推送、云端发布或修改现有 Navidrome 配置。

## 已实现

| 范围 | 实现与当前限制 |
| --- | --- |
| 工程 | React 19.3、Vite 8.3.4、TypeScript 6.0.3、pnpm lock；TS 7 暂与当前 Lint 不兼容，因此固定兼容版本 |
| 认证 | URL/base path 校验、UTF-8 token/salt、内存凭据、退出清理、查询认证失效回到登录；API key 尚未做 |
| 数据接口 | failed envelope、超时/取消、扩展声明、GET/声明后的表单 POST、字符串 ID、多歌手展示 |
| 页面 | 登录、首页、专辑/歌手、分类搜索、收藏、歌单、此设备历史、设置 |
| 播放 | 单实例音频、状态反馈、进度/音量、原始/兼容策略、快速切歌过期 promise 保护、Media Session（按支持启用） |
| 队列 | 重复条目独立 ID、追加/下一首、调序/移除、随机/循环、替换撤销、本机暂停恢复、同账号标签页播放信号协调 |
| 歌词 | 服务端逐行/静态/无歌词降级，点击定位、字号、手动跟随、全局延迟；正确转换 OpenSubsonic offset 符号 |
| 歌单与收藏 | 收藏返回后刷新；歌单草稿编辑、重命名、增曲、移除与重排、changed 检查、保存后读回核实；超时不自动重放 |
| 存储与收听 | IndexedDB 隔离账号队列/历史，localStorage 非敏感偏好；有效收听阈值与单次提交；playbackReport 用 song 与 ignoreScrobble=true |
| 部署准备 | Docker 两阶段构建、Nginx 同源代理、Compose 仅绑定本机；尚未运行容器 |
| 依赖记录 | 13 个生产依赖的完整随包 LICENSE 已生成；未引入 AMLL/GPL/AGPL 参考项目代码 |

以上为可运行基线，不表示 M0–M4 已全部验收。当前没有做智能歌单、搜索索引、在线歌词、歌词导入、服务端队列同步、PWA、逐词/双语、EQ/ReplayGain、Crossfade、无缝或离线歌曲。

## 自动化验证

`npm.cmd test`：40 个测试、7 个文件。覆盖：重复歌曲身份、随机与循环边界、曲目调序、歌词定位、短曲/未知时长收听、URL/base path、Unicode 密码、HTTP 200 业务失败、代理 HTML 响应、扩展失败回退、POST 重复参数、写冲突/读回核实/超时不重试、退出取消、歌词 offset、快切旧 promise、暂停删当前、seek 不计收听、只提交一次、播放器清理、播放报告、中文 IME 结束后才查询、封面播放按钮不导航、空专辑不替换队列。新增：进度预览只提交一次、旧曲目预览隔离、歌词/队列切换不打断播放、歌词偏移定位、静音恢复、弹窗进出动画/减少动态效果、端口占用/保留回退和配置错误传播。

Lint、类型检查、生产构建分别执行；最终结果以本次工具输出为证据。产物只是静态网页，不携带用户凭据。

自动化用模拟 transport 和音频事件测试边界；不等于真实服务、真实浏览器音频格式或移动后台通过。暂无自动化 E2E 命令；手工浏览器检查见下节。

## 发布前仍需完成

1. M0 真实服务能力清单与代表性曲目，浏览器认证/封面/原始流/兼容流/seek。
2. M2 30 分钟连续播放、弱网/认证失效、重复循环、多标签页竞争、快切/删除与恢复的长期回归。协调信号不等于原子播放锁。
3. M3 大库与大队列性能；随机专辑跨页结果可能变化，目前尚未做服务端稳定随机集合。当前队列未虚拟化，不能宣称 1,000 条操作延迟已达标。
4. 权限与并发保存矩阵；changed 是非原子检查，多客户端同时写仍可能冲突。收藏目前是确认后刷新，没有实现乐观更新。
5. seekable 范围、更精细的失败分类与有界重试/跳过；当前音频失败暂停、由用户重试/切兼容模式。失效恢复项仍由实际请求失败解释。
6. 歌词偏移按曲目记忆、手机完整歌词体验、无障碍焦点/读屏与恢复损坏数据检查；当前偏移是全局偏好。
7. 手机 iOS/Android 实机后台、锁屏、系统媒体键、软件音量；本次手机宽度来自桌面浏览器模拟。
8. Docker 实际构建、nginx -t、容器到宿主/同网络 Navidrome 路径；此电脑没有 Docker。基础镜像 digest 和 HTTPS 部署在正式发布前固定/验证。
9. 正式开源 LICENSE、版本说明和发布验收；当前保留源代码，不宣布发布就绪。
