# 开发计划与里程碑

> 历史排期说明（2026-10-22 校订）：以下保留 2026-10-13 的原始里程碑与工期估算，不代表当前日历承诺。持久化、迁移、备份恢复、网络/双语歌词、桌面歌词和音乐推荐现已接入，部分实现顺序已越过原计划。当前状态与未测边界见 [开发记录](09-development-status.md)，现行接入与交互约定见 [AGENTS.md](../AGENTS.md)。不要根据旧阶段编号恢复已取消的交互，或因本文列有任务就自动扩大当前授权范围。

日期：2026-10-13。用户已确认 Tooku 产品名与 Apple Music 白色视觉方向，并授权初始化本地 Git。工程、界面与核心播放功能已形成可运行开发版；本计划保留为里程碑验收基线。实际进度、通过证据与未完成项见 [开发记录](09-development-status.md)，不能把提前实现页面等同于里程碑全部验收。以下工期为一名熟悉前端的开发者、能访问测试账号与授权样本时的估算，不等于日历交付承诺。

## 路线与范围

先验证接口与音频，再完成视觉原型、播放器核心和日常功能，最后发布首版；随后迭代中文搜索、增强歌词和 PWA。基础产品不得等待高级音频实验。

```mermaid
flowchart LR
    M0[M0 接口与真实播放验证] --> M1[M1 视觉与页面骨架]
    M1 --> M2[M2 播放器与队列]
    M2 --> M3[M3 音乐库与日常功能]
    M3 --> M4[M4 首版验收与部署]
    M4 --> M5[M5 中文搜索与增强歌词]
    M5 --> M6[M6 PWA与可选服务]
    M4 --> X[P2 高级音频独立实验]
```

首版 M0–M4 约 **21–32 个有效工作日**；预留约 20%–25% 调整时间，建议排期 **26–40 个工作日**。M5–M6 再约 16–25 个工作日；P2 不计入承诺。真实音乐库或浏览器能力有偏差时先更新范围与估算。

## M0：工程与服务联调（2–3 日）

| 任务 | 交付物 | 验收条件 |
| --- | --- | --- |
| M0-01 工程初始化 | React/TS/Vite、pnpm lock、lint、typecheck、最小测试配置 | 本地可启动与构建；README 更新为实际命令 |
| M0-02 transport 与认证（AUTH-01） | URL/base path、编码、JSON envelope、内存认证、类型错误 | 用户手动登录；中文密码正确；失败不进入应用 |
| M0-03 能力与字段样本 | 脱敏接口记录、扩展清单、可选字段适配 | 实测而非按版本推定歌词、POST 等支持 |
| M0-04 音频纵向验证 | 曲目列表 → 点击真歌 → 播放/暂停/seek | 一首原始流和一首需要兼容策略的样本；返回页面持续播放 |
| M0-05 访问路径 | 浏览器直连/同源代理验证记录 | 认证、封面、音频三类访问成功；手机连接地址有说明 |

**门槛：真实歌曲可播放和可解释地失败。** 只展示 mock 页面或拿到 HTTP 200 不算完成。账号通过登录页输入，不放入文档或环境变量提交。

## M1：视觉原型与页面骨架（3–5 日）

任务：实现主题 token、AppShell、基础控件、路由、登录和首页；制作专辑、队列、全屏歌词的可交互原型；验证中文长文本、空、加载、无封面和错误状态。

交付：桌面/手机、浅/深主题的五类关键页面；少量 mock 仅用于极端状态，真实数据页面明确可辨。确认视觉方向后再扩展细节。

验收：360px、768px、1440px 布局可操作；键盘焦点、弹窗与输入法基本正常；页面切换不重建音频。此阶段不能将视觉原型误标为完整播放器。

## M2：播放器核心与队列（6–9 日）

| 任务 | 对应 PRD | 验收重点 |
| --- | --- | --- |
| M2-01 引擎与状态机 | PLAY-01 | loading/blocked/buffering/error 可区分；快速换曲旧响应不污染 |
| M2-02 队列算法与控件 | QUEUE-01 | 顺序、随机、循环、插入、删除、调序、重复项与空队列 |
| M2-03 本机恢复 | RESTORE-01 | 按用户隔离；重新登录后暂停恢复；不持久化认证 URL |
| M2-04 常驻控制栏/全屏 | PLAY-01、UX-01 | 页内/全屏状态一致；媒体键按能力可用 |
| M2-05 基础歌词 | LYRIC-01 | 逐行、静态、无歌词、正负偏移、点击定位 |
| M2-06 收听与本机历史 | HISTORY-01 | 暂停/seek 不虚增；同一 occurrence 不重复主动提交 |

验收：连续 30 分钟播放、反复路由切换、断网/恢复、拖动进度、移除当前项和连续快切通过；算法边界有自动化测试。没有逐词数据的曲目仍能正常听。

## M3：音乐库、搜索、收藏与歌单（7–10 日）

任务：专辑/歌手分页与详情、多碟曲目顺序、搜索分类与旧请求取消、收藏读写、普通歌单 CRUD/调序、此设备历史页、设置、操作反馈与回滚。

对应 PRD：LIB-01、SEARCH-01、FAV-01、LIST-01、HISTORY-01、UX-01。写入联调使用专用测试歌单；真实用户歌单只执行用户明确操作。

验收：中文 IME 不提交半成品查询；重复曲目和长歌单保存可读回核实；只读/他人歌单解释权限；写超时显示待核实；缺字段与分页末尾不丢项/重复项。1 万首性能样本若不具备，必须报告实际规模，不拿小样本替代达标结论。

## M4：首版回归与自托管发布（3–5 日）

任务：整体验收、性能样本、可访问性修复、错误脱敏、用户隔离、静态构建、同源反代、Docker/Compose 示例、配置说明、版本与第三方许可记录。补齐 README 的安装/运行/部署命令。

门槛：全部 P0 有完成证据或明确的服务/浏览器降级说明；严重播放/数据/身份问题清零；部署从干净环境可复现。移动端最低通过选曲、播放、队列与歌词；无法实机验证的锁屏后台能力必须标为未测。

发布产物应包含版本、固定依赖、变更说明、兼容性矩阵和已知限制。建立正式开源 LICENSE 前确认许可路线；本轮不替用户决定开源或商业策略。

## M5：中文搜索与增强歌词（8–12 日）

任务：词典/繁简转换选型、增量索引 Worker、全库覆盖进度、拼音/首字母/用户别名、多音字修正；songLyrics v2 与译文/注音/逐词适配；用户歌词导入预览与本机覆盖；AMLL 可选技术验证。

对应 PRD：CN-01、LYRIC-02、LYRIC-03。验收：离线/部分索引显示覆盖范围，不能假装全库结果；权限/库变化可删除旧索引；中文与 Emoji 字节索引正确；无逐词时间戳降级；低动效与低性能模式可用。

依赖：M0 能力证据、M2 稳定时钟；AMLL 引入依赖许可评估完成，不阻碍基础歌词自研。

## M6：PWA 与日常体验扩展（8–13 日）

任务：应用壳缓存、升级提示和缓存清理；睡眠定时/命令面板；服务端队列手动同步与冲突选择；用户文件歌单导入/导出；可选在线歌词提供方验证。

对应 PRD：PWA-01、UX-02、SYNC-01、IMPORT-01、LYRIC-04。验收：无网络可打开缓存应用壳但明确流媒体不可用；缓存不含认证请求；导入先预览再写入；在线提供方禁用时无外部请求；重复曲目队列恢复按能力正确。

上述估算以用户文件导入和一种在线歌词提供方为边界，不含国内平台分享链接解析。优先 PWA 壳与队列同步；增加提供方或复杂匹配规则时按独立任务重估，不能为赶工删掉匹配预览或写入核实。

## P2：独立技术实验

ReplayGain、EQ、Crossfade、gapless、离线歌曲和声学推荐分别建 spike。每项产出：样本/浏览器矩阵、测量方法、依赖、内存/后台成本、失败降级、是否进入产品的结论。不得把“桌面参考项目支持”作为网页版完成证据。

## 风险、触发条件与调整

| 风险 | 触发信号 | 调整 |
| --- | --- | --- |
| 认证/CORS/子路径 | 命令行成功而浏览器失败 | 固定上游同源代理，保留服务路径，不绕过用户认证 |
| 格式/转码/seek | 真歌不能解码或拖动错误 | 原始/兼容策略分测，UI 提示可用能力 |
| 歌词缺失或不完整 | v2 声明存在但无 cue | 基础逐行/静态保底，逐词功能按曲目显示 |
| 许可路线 | 准备引入 GPL/AGPL 代码 | 先评估复用范围与发布方式，保留独立简版实现 |
| 大库索引 | 建索引卡顿或加载成本过高 | Worker、分页/增量、可暂停；延后全库搜索承诺 |
| 移动后台 | 页面冻结/系统限制 | 页面基本播放优先；实机记录限制，高级处理默认关闭 |
| 写入冲突 | 保存后与草稿不同/超时 | 重新读取并提示冲突，保留草稿，不盲重试 |
| 外部歌词国内访问 | 提供方超时或不可达 | 默认关闭、超时回退，不耦合播放主路径 |

## 每项任务的完成定义

任务卡记录：问题/预期行为、对应 PRD ID、依赖、实现范围、验证证据、已知限制。代码审阅与相关测试通过后更新状态；文档和真实行为同步。暂停功能或发现能力不符时改任务范围，不只把复选框勾为完成。

以上为原始计划，不作为当前“下一次任务”指令。真实登录与部分 FLAC 播放已有历史证据，但 M0–M4 的完整稳定性、权限、性能和部署门槛仍未全部验收；当前缺口以开发记录为准，是否开展由具体任务授权决定。
