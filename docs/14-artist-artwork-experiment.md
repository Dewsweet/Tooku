# 歌手图片补齐试验

日期：2026-10-20。范围为详情页缺图兜底与公开来源的只读试验；未修改 Navidrome 配置、安装插件或写入音乐文件，也未接入在线歌词。

后续界面迭代已统一柔化背景与前景图片，并增加按账号保存的手动歌手图片；数据边界见 [服务端持久化](13-server-persistence.md)。以下“已实现的页面行为”记录联网试验时的阶段，不覆盖之后增加的手动换图。联网补图目前仍未启用。

## 已实现的页面行为

1. 优先显示 Navidrome 明确返回的歌手图片。
2. 缺图或图片失败时，从当前库、当前歌手的专辑中依稳定专辑 ID 尝试封面。排除明确属于其他专辑歌手的记录，保留服务器未提供 artistId 的旧数据兼容。
3. 专辑封面保留正方形，横幅使用同一封面的柔化背景；不把它标作真实歌手照。全部候选失败后使用主题渐变，失败候选在当前详情实例内不重复请求。
4. 横幅下方的播放与专辑区域使用纯色 `--bg`。

不新增持久化结构，不保存认证 URL；切页、切库和当前播放状态的约定不变。歌手列表未调整。

## 联网试验方法

使用 `scripts/probe-artist-artwork.ts`，无新增依赖：

```powershell
# 默认 30 个公开样本；不连接或读取你的真实曲库
node scripts/probe-artist-artwork.ts

# 可选自定义 JSON 数组，每项仅使用 name、group，最多 50 项
node scripts/probe-artist-artwork.ts .local/artist-samples.json
```

结果保存在 Git 忽略的 `.local/artist-artwork-probe.json`。公开样本包含中文 8 个、日本艺名 8 个、韩文 6 个、同名/短名 2 个、组合名 6 个。与用户曲库实际缺图分布无关。

分别查询网易云的匿名歌手搜索与 QQ 音乐网页的匿名歌手搜索；本次没有登录、Cookie 或第三方公共代理。端点为非官方稳定性承诺接口，后续可能变化。图片仅检查 HTTPS HEAD 的状态和图片 Content-Type，不下载图片文件。

完整保留原始标签。搜索词做 NFKC、首尾空白和空白折叠；`中文（日文）` 同时搜索完整写法及括号内外，拆分结果只作为待确认候选。`CV.`、Live、作曲等说明性括号不拆分。姓名/返回别名相等且只有一个候选时记录唯一候选；多个候选记为歧义，不取第一条。未做专辑作品交叉核实或图片内容人工确认。

## 本次实际结果

| 样本组 | 数量 | 网易云唯一候选且图片可访问 | QQ 音乐唯一候选且图片可访问 |
| --- | ---: | ---: | ---: |
| 中文 | 8 | 6 | 7 |
| 日文/日本艺名 | 8 | 7 | 3 |
| 韩文 | 6 | 2 | 2 |
| 同名/短名 | 2 | 0 | 0 |
| 中文（日文/韩文）等组合名 | 6 | 5 | 1 |
| 合计 | 30 | 20 | 13 |

两源合计覆盖 23 个不同样本。网易云为 15 个直接名称/别名候选、5 个拆分名称候选，6 个样本存在歧义；QQ 为 12 个直接候选、1 个拆分候选，8 个样本存在歧义。全部搜索请求完成，无请求失败；不代表长期可用性。

例如 `宇多田光（宇多田ヒカル）`、`中岛美雪（中島みゆき）`、`坂本龙一（坂本龍一）` 在网易云找到拆分候选；`李知恩（아이유）` 两源均存在歧义。`周杰伦` 也出现名称/别名重叠候选，证明不能仅凭知名度或第一条结果决定绑定。

这些是**候选覆盖与图片可达性**，不是正确识别率、图片质量评分，也不是两家平台总体覆盖率。页面本轮没有自动采用这些联网候选。

## 后续接入选择

本次结果支持优先评估网易云作为补充源，QQ 音乐作为备用。自动绑定前应结合当前库代表专辑或曲目核实身份；同名、组合名拆分和弱匹配提供人工确认，确认后按平台 ID 绑定，保留来源、人工覆盖和恢复默认能力。

优先评估 Navidrome 侧元数据插件，使 Tooku 与其他客户端共用补图结果；如果需要账号级选图与来源管理，再设计 Tooku 后端的补充源。现有 [网易云插件](https://github.com/yuehei/netease-music-plugin) 依赖额外的兼容 API 服务，包含精确匹配和人工 ID 映射；本轮只检查了说明和实现，未验证其与本机部署的运行兼容性。插件安装、配置与长期缓存不包含在本轮页面兜底实现中。

参考：[网易云社区 API](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced)、[QQ 音乐社区接口说明](https://github.com/Rain120/qq-music-api/blob/master/docs/README.md)、[Navidrome 图片解析](https://www.navidrome.org/docs/usage/library/artwork/)。后续歌词仍需单独核对歌曲版本与时长，不能直接沿用歌手名称绑定结果。
