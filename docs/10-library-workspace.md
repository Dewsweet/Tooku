# 歌单优先的主界面

历史记录：2026-10-14。2026-10-19 的头部/侧栏布局已调整，当前说明与人工验收见 [主页改版清单](11-home-refresh-and-checklist.md)。

日期：2026-10-14。白色视觉延续 Apple Music，布局参考用户的 MusicBee 截图。开发分支为 `codex/library-workspace`。

## 操作

- 左上角统一账户与设置：切换账号、明暗模式、五种主题色、播放侧栏和减少动态效果。切换账号清除内存认证，保留本机分类与暂停快照。
- 左侧选择真实曲库；主导航和歌单树独立滚动。音乐库入口可选歌单、歌曲、专辑，各曲库独立记住，也可在设置中指定。
- 歌单树旁加号创建文件夹；进入文件夹可建子文件夹。文件夹菜单支持重命名、更改上级、删除，禁止移动到自身或子文件夹。删除只将歌单和子文件夹移到上一级，不删除服务器歌单。
- 歌单卡片菜单或详情的文件夹按钮可更改所属曲库与文件夹。新歌单属于当前曲库/文件夹；添加歌曲时只列出当前库有编辑权限的歌单。
- 点击单曲从该位置接续整张歌单，保留顺序及重复曲目。底栏歌曲名跳转专辑，歌手名跳转歌手，封面展开播放器；移除额外歌词入口和状态小图标。
- 桌面右侧为接下来播放、详情/歌词，可隐藏；手机通过底栏队列或完整播放器查看。

## 数据边界

真实曲库来自 [getMusicFolders](https://opensubsonic.netlify.app/docs/endpoints/getmusicfolders/)，仅列账号可访问的库。歌曲、专辑、歌手列表、搜索、收藏请求带 musicFolderId，缓存键包含曲库 ID。getArtist 聚合多个库的专辑，因此歌手详情与当前库 getAlbumList2 的分页结果取交集；大库首次详情可能有额外分页成本。

标准 [getPlaylists](https://opensubsonic.netlify.app/docs/endpoints/getplaylists/) 没有曲库/文件夹参数。[Navidrome 多库设计](https://www.navidrome.org/docs/usage/features/multi-library/)允许跨库歌单。Tooku 将分类保存到 localStorage 的 `tooku-library-organization`，按服务地址、账号、曲库 ID 隔离；服务器保留歌单内容与顺序。分类不跨设备同步，也不改变访问权限或建立歌单副本。清除浏览器数据会清除分类，暂未提供导入导出。

没有分类的已有歌单显示在首次识别库的根目录，默认归属 ID 被记住，避免服务器返回顺序变化后跳库。可手动移动。直接打开已有专辑/歌单链接仍按服务器权限读取；切换库不打断当前队列。创建曲库和分配用户权限仍在 Navidrome 管理。

## 验证

- 49 个测试、9 个文件；新增曲库参数和数字 ID、共享歌手边界、账号/曲库分类隔离、防循环、删除保留内容、嵌套创建与移动、添加歌单范围、单曲接续歌单、底栏链接。
- 真实账号返回 Music Library 与 Aublm，分别检查歌单与专辑入口；切换后保留独立视图和分类。
- 真实《周杰倫》歌单 147 首可读；从《可爱女人》播放建立 147 条队列，暂停保留位置，底栏链接进入对应页。未修改服务器歌单内容。
- 1440×900 与 360×800、浅色/深色及莓红/海蓝已检查。手机导航关闭区域和背景焦点隔离已修正；无横向溢出，仅为桌面浏览器模拟。
- 专用测试账号本机分类中建立“歌手精选”，将《周杰倫》放入其中验证操作；仅分类元数据改变。
- 刷新页面后重新认证，文件夹、归属和暂停队列恢复；认证凭据未持久化。

长期播放、真实写入权限与并发保存、列表虚拟化、分类同步和 Docker 仍需后续验收。
