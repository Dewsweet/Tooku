# 主页改版与人工验收清单

日期：2026-10-19。布局参考用户提供的 Spotify 截图，保留 Tooku 的明暗模式与主题色。

## 本轮改动

- 全局头部：左侧 Logo 回主页，中间主页按钮与可输入的搜索栏，右侧播放侧栏开关、设置和账户头像菜单。
- 三栏采用有间距的圆角面板，增加背景层次、封面阴影、悬停反馈和短过渡；左栏移除曲库选择器和大封面，只保留歌曲、专辑、歌手、收藏、最近在听及独立歌单树。
- 独立主页：当前曲库数量概览、快捷入口、继续聆听、歌单、最近加入与常听专辑；可切换全部/歌单/专辑/歌曲。概览按当前库的专辑目录汇总，缺少 songCount 时不显示不完整的歌曲总数；大库首次可能需要额外分页读取。
- 曲库切换移到设置。原来的曲库浏览偏好保留，专辑/歌曲偏好会影响主页首次打开时的内容筛选，默认展示综合主页。
- 右侧为纵向的封面、歌词、歌曲详情和播放队列，可分别显示/隐藏及上下调整顺序。右侧顶栏的调整按钮或设置页均可配置，也能恢复默认。较窄窗口通过顶部开关打开覆盖侧栏。
- Tooku 独立头像：设置中选择 JPG/PNG/WebP，最大 5 MB，裁为方形并缩小到 256px；头像只在当前浏览器按账号保存，不上传 Navidrome。主题和侧栏布局也是本机设置。
